# amaranthaceae-biogeography-c4-evolution
Scripts used to reproduce the analyses presented in the manuscript "Repeated intercontinental dispersal, ecological transitions, and C4 innovation shaped the evolutionary history of Amaranthaceae s.s."

- 01. divergence-time estimation in BEAST2 v2.7.6 (Bouckaert et al., 2019) using a node-dating: xml file prepared in BEAUTI
- 02. ancestral area reconstruction using BioGeoBEARS v1.1.3: R script for DEC, DIVA-like, and BayArea-like models and biostochastic mapping
- 03. ancestral habitat reconstruction in RevBayes: .Rev code for analysis
- 04. C3/C4 ancestral state reconstruction in RevBayes: .Rev code for analysis
- 05. trait correlation analyses in RevBayes: .Rev code for analysis
- 06. state-dependent diversification analyses in RevBayes: .Rev code for BISSE and HISSE analysis for habitat and phytosynthesis
